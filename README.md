 Sistema de Desconto Progressivo - Loja Online (match/case)

Projeto desenvolvido como Atividade de Recuperação para demonstrar a aplicação de técnicas de programação estruturada, lógica condicional e uso do comando de decisão match/case em Python.

 Descrição do Projeto

O programa simula um caixa de loja online que calcula o desconto aplicado a um pedido e determina o valor final a ser pago com base no valor total da compra.

 Regras de Desconto:

Compras abaixo de R$ 200,00: 5% de desconto.

Compras entre R$ 200,00 e R$ 299,99: 10% de desconto.

Compras a partir de R$ 300,00: 15% de desconto.

 Tecnologias e Conceitos Utilizados

Linguagem: Python (versão 3.10 ou superior)

Conceitos Aplicados:

Lógica de decisão estruturada com match/case e guard conditions (if).

Entrada e saída de dados via terminal (input e print formatados).

Validação de dados de entrada (try / except).

Formatação monetária em padrão numérico com duas casas decimais.
